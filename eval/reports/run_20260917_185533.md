### Methodology disclosure

- **PDF parsing is mocked.** Both branches receive pre-extracted clause arrays; this eval tests reasoning, not PyMuPDF robustness. Documented in `eval/RUBRIC.md` §5 and `eval/runners.py`.
- **Production prompt and tool schemas imported, not mirrored.** `eval/prompts.py` imports `config.SYSTEM_PROMPT`; `eval/runners.py` uses `backend.tools.TOOLS`; `lookup_playbook` and the schema validator are the production functions.
- **Scorers are deterministic.** No LLM-as-judge. Matching is canonical-topic + section-overlap (lenient substring either way). See `eval/scorers.py`.
- **Per-tier macro-average.** Overall scores weight each tier equally, preventing the larger `clear_conflict` tier from dominating.
- **is_optional gold conflicts.** Missed optional golds do NOT count as false negatives (RUBRIC §1 Rule 4 ambiguity carve-out).
